# Payout — учёт премий для фракций

Веб-приложение для еженедельного расчёта и выдачи премий. Заменяет таблицы WPS и Google: ввод с клавиатуры, мгновенный расчёт, ведомость, закрытие недели одной кнопкой, архив, статистика и отчёт `.xlsx` для админов.

Подробный план и решения — в [PLAN.md](PLAN.md).

## Запуск

```powershell
npm install
npm run dev
```

Откройте http://localhost:5173.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | дев-сервер |
| `npm test` | тесты движка расчёта и отчёта (сверка с цифрами WPS) |
| `npm run typecheck` | проверка типов |
| `npm run build` | сборка в `dist/` |

## Устройство

- `src/engine/` — движок расчёта (чистые функции): основа → множитель → корректировки → лимит → округление → комиссия.
- `src/data/templates.ts` — пресеты правил (баллы как в LSPD, бюджет и доли как в SASPA, пустой) — без людей.
- `src/dev/demo.ts` — демо-данные только для разработки: выдуманные игроки, количества действий из реальной недели WPS. В продакшен-сборку не попадают.
- `src/store.ts` — данные (в прототипе хранятся в браузере, localStorage), история для Ctrl+Z, журнал.
- `src/export/report.ts` — отчёт `.xlsx`: «Итог», «Детализация» (живые формулы), «Тарифы».
- `src/pages/` — экраны: обзор, ввод недели, ведомость, архив, сотрудники, настройки.

## Горячие клавиши

`Ctrl K` — поиск и команды · `Alt 1–6` — разделы · `Ctrl Z / Ctrl Shift Z` — отменить / повторить.
На экране ввода: стрелки, цифры, `Enter`, `Tab`, `+`/`Пробел`, `−`, `Del`, `Esc`.
